# Banking Application

A secure, enterprise-grade core banking backend built with Java 21 and Spring Boot.

## Features

- **Account & Transaction Management:** Core banking workflows and balance tracking.
- **Database Migrations:** Automated schema versioning using Flyway and MySQL.
- **Security:** Token-based authentication and role-based access control with Spring Security.
- **Observability:** Production-ready metrics and health probes via Spring Boot Actuator.

---

## Prerequisites

- **Java Development Kit (JDK):** Version 21 or higher
- **Build Tool:** Apache Maven 3.9+
- **Database:** MySQL 8.0+
